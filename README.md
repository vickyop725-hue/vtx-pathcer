## 📌 Features
- **Personal APK Backup:** Scripts to extract and repackage APK files for personal backup.
- **Testing Utilities:** Tools to test Android application behavior in sandbox environments.
- **Educational Guides:** Basic guides on how Android permissions and manifests work.
